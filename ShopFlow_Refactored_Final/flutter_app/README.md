# ShopFlow Flutter App

This folder contains the ShopFlow mobile client.

The Flutter app:

- authenticates users with Firebase Auth
- persists buyer and seller data in Firestore through the ShopFlow subsystem services
- uploads prerequisite files with Firebase Storage
- presents buyer and seller workflows through a single orchestration layer: `lib/services/service.dart`

For the full project overview, setup guide, architecture explanation, and workflow documentation, read the repository root README:
